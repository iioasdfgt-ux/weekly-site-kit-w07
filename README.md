# 주간 사이트 제작 키트 · 사용법 (2학기 공통 · 4~15주)

## 이 키트의 표시 두 가지
- `밑줄` — 내가 내 것으로 바꿔 넣는 자리입니다.
- **굵은 글씨** — 그대로 치거나 그대로 찾는 이름(폴더·파일·명령어)입니다.

## 준비 (처음 한 번)
### 수업에 오기 전에 (4주 한 번)
2·3주에 쓴 **planning** 폴더를 **노트북에 넣어 옵니다.** 어느 폴더 안에 있는지는 **이전기록/읽어주세요.md**에 학년별로 적어 두었습니다. 이 폴더가 없으면 Claude가 2·3주에 이미 답한 것을 처음부터 다시 묻습니다.

### 수업에서 (4주 20분쯤)
1. **단톡방에 올라온 zip**을 받아 **바탕화면**에 풉니다. 폴더 위치는 **바탕화면/weekly-site-kit**으로 못 박습니다 — 이름도 위치도 바꾸지 않습니다. 매주 이 폴더를 다시 열어 쓰고, 주마다 새로 받지 않습니다. 새로 받으면 지난주 결과가 든 **weeks** 폴더가 사라집니다.
   - **윈도우에서 풀었다면** **weekly-site-kit** 폴더를 열어 안에 또 **weekly-site-kit**이 있는지 봅니다. 있으면 **안쪽 폴더를 바탕화면으로 꺼내고** 바깥 빈 폴더는 버립니다. 이 중첩이 "폴더를 못 찾겠다"의 가장 흔한 원인입니다.
   - 폴더 안에 **README.md**·**CLAUDE.md**·**주제카드**·**templates**가 **한 층에** 보이면 제대로 풀린 것입니다.
2. **.claude** 폴더는 숨김입니다. 맥 Finder는 **⌘ Shift .** 를 누르고, 윈도우는 탐색기 '보기'에서 "숨긴 항목"에 체크해 **.claude** 폴더가 들어 있는지 확인합니다.
   - **.claude가 안 보이면** 압축을 풀 때 빠진 것입니다. zip을 지우고 단톡방에서 다시 받아 풉니다. 이 폴더가 없으면 Claude가 역할 규칙을 못 읽어 순서 없이 아무 파일이나 만듭니다.
3. **가져온 planning 파일을 바탕화면/weekly-site-kit/이전기록/에 복사해 넣습니다.** Claude가 이걸 먼저 읽고 이미 답한 것은 다시 묻지 않습니다. 못 가져왔으면 첫 **시작** `4주`에서 **없음**이라고 답하고 넘어갑니다.
4. Claude Code 앱에서 이 폴더를 엽니다. **CLAUDE.md** 맨 위 이름 칸을 채웁니다.

## 7주 패치 적용하기 (7주 수업 20–30분 구간의 첫 5분)
5주·6주에 해 본 것과 같은 방법입니다. 이번 패치 **weekly-site-kit_W07패치.zip**으로 세 가지가 바뀝니다.
- **아카이브에 4장 '물건'이 생깁니다.** 6주 시스템(**W06-A 모듈형** · **W06-B 사례형**)을 그대로 쓰고 4장만 더해도 되고, 새 시스템 **W07-A 카드형**으로 아카이브 전체를 갈아입혀도 됩니다. 어느 쪽이든 제출할 수 있습니다. 메뉴는 시선·사람·공간·물건·기준 다섯 칸이 되고, 한글로 할지 영문으로 할지는 Claude가 먼저 묻습니다.
- **배포 전에 한글 검수를 합니다.** 사이트를 다 만든 뒤 입력창에 **한글 검수**라고만 치면(같은 일을 하는 명령 `/hangul-check`) 지금 주차 사이트의 화면 문장을 검수관이 짚어 주고, 내가 고른 것만 고칩니다. 내 말투는 바꾸지 않습니다.
- **처음으로 인터넷 주소에 올립니다.** **배포 안내해 줘**라고 치면 deploy-guide가 GitHub와 Netlify로 올리는 길을 한 단계씩 짚어 줍니다. 가입·로그인·권한 허용 버튼과 마지막 올리기 명령은 내가 직접 누르고 칩니다. 비밀번호는 Claude에게 알려 주지 않습니다.

패치는 지금 쓰는 키트 위에 덮어쓸 뿐, 키트를 새로 받지는 않습니다.

**내 기록은 안전합니다.** 패치에는 **weeks**·**나에대해.md**·**MEMORY.md**·**이전기록**·**취향축.md**가 들어 있지 않고, 덮어쓰기는 Claude가 이것들을 건드리지 않는 절차로 합니다. **CLAUDE.md** 맨 위 학생 이름도 그대로 남습니다. Finder나 탐색기로 폴더를 직접 끌어다 덮지 않습니다 — 폴더가 통째로 바뀌면 지난 주 주제카드 같은 파일이 지워질 수 있습니다.

1. zip을 받아 **바탕화면**에 풉니다. **바탕화면/weekly-site-kit_W07패치** 폴더가 생기면 됩니다. 윈도우에서 안에 같은 이름 폴더가 또 있으면 안쪽 폴더를 바탕화면으로 꺼냅니다.
2. Claude Code 앱에서 **weekly-site-kit**을 연 채로 아래를 그대로 칩니다. 바탕화면 폴더를 읽어도 되는지 묻는 창, **.claude** 폴더나 **CLAUDE.md**에 써도 되는지 묻는 창이 뜨면 모두 허용합니다.
   > **패치 적용**
   > **바탕화면/weekly-site-kit_W07패치/CLAUDE.md**의 '패치 적용' 절차대로 해 줘.
3. Claude가 무엇을 덮는지 한 줄로 먼저 말하고, 끝나면 바뀐 파일 목록을 보여 줍니다. 중간에 끊겼거나 허용 창을 거부했으면 **패치 적용**을 다시 치면 됩니다. 목록에 **weeks**가 없고 **시스템/07주/** 안에 **w07a-card** 폴더가 있으면 제대로 된 것입니다.
4. Claude Code에서 **새 대화**를 열고 **시작** `7주`를 칩니다. 열려 있던 대화는 옛 규칙을 기억하고 있어서, 새 대화를 열어야 바뀐 규칙을 읽습니다.
5. 새 대화에서 "**한글 검수**라고 치면 무엇을 하나요?"라고 물어 확인만 합니다. 지금 주차 사이트를 검수하는 절차라고 답하면 한글 검수 팩도 잘 들어간 것입니다. 아직 사이트가 없으니 검수를 실제로 돌리지는 않습니다.

### 7주 전에 집에서 해 둘 것
- 물건 다섯 개를 **같은 배경**에서 찍어 옵니다(물건마다 1~2장).
- **GitHub**(github.com)에 가입하고 이메일 인증까지 마칩니다. **Netlify**(netlify.com)에는 GitHub 계정으로 로그인해 둡니다. 둘 다 무료 요금제이고, 카드 번호를 묻는 화면이 나오면 거기서 멈춥니다.
- 비밀번호는 내 머릿속과 내 화면에만 둡니다. Claude 입력창에 붙여 넣지 않습니다.

## 매주 하는 일 (7주 기준)
1. 입력창에 **시작** `7주`처럼 주차를 붙여 칩니다. Claude가 **주제카드/**`07`**주.md**를 읽고 **weeks/**`07`**/** 폴더를 만듭니다.
2. 이번 주 사진은 집에서 미리 찍어 오고, 고르는 일은 수업 중 20–30분에 합니다. 고른 사진은 이름을 바꿔 **바탕화면/weekly-site-kit/weeks/**`07`**/site/assets/**에 넣습니다. 못 찍어 온 학생이 그 시간에 무엇을 하는지는 7주 주제카드에 적어 두었습니다.

4~6주의 시간표는 그 주 주제카드(**주제카드/**`04`~`06`**주.md**)에 기록으로 남아 있습니다. 8·14·15주는 배포·발표가 들어가 시간표가 다르니 Claude가 그 주 주제카드를 보고 안내합니다. **weeks/04/**~**weeks/06/**은 그대로 두면 됩니다.

### 인터넷에 올라가는 것과 올라가지 않는 것
| 올라감 (누구나 볼 수 있음) | 올라가지 않음 (내 노트북에만) |
|---|---|
| **publish/taste-archive/** 안의 파일 — 사이트 화면(index.html·CSS·JS)과 화면에 쓴 사진, 사진 출처 표 | 기획·인터뷰 답·회고(**weeks**의 .md 파일) · **나에대해.md** · **취향축.md** · **choices.md** · **이전기록** · 검수 전 원본(**_review**) · 고르다 남긴 사진 |

그래서 배포 전에 얼굴·집 주소·연락처가 화면이나 사진에 보이지 않는지 한 번 더 봅니다. 사진 파일 이름은 영문 소문자로 씁니다 — 내 노트북에서는 `Obj1.JPG`도 뜨지만 인터넷 주소에서는 대문자와 소문자를 다른 이름으로 봐서 사진이 안 뜹니다.

## 입력창에 입력하는 프롬프트 다섯
| 말 | 언제 쓰나 |
|---|---|
| **다음** | 이 단계를 다 했으니 다음으로 갈 때 |
| **다시** | 방금 나온 결과가 마음에 안 들 때 |
| **확정** | 지금 보여 준 것이 맞을 때 — STEP 01(기획)과 STEP 03(시스템 읽기) 두 군데에서 씁니다 |
| **끝** | STEP 05까지 마치고 회고로 갈 때 |
| **미정** | 지금 답이 안 떠올라 나중에 정할 때 |

답이 막히면 **후보 세 개를 줘**라고 쳐도 됩니다.

## 주소를 찾을 때 — 링크모음.md
5주부터는 레퍼런스를 찾으러 모음 사이트에 가지 않습니다. 이번 주 시스템과 각 레퍼런스 주소는 주제카드의 '이번 주 시스템' 표에 있습니다. **링크모음.md**는 무료 사진 사이트 세 곳의 주소를 찾을 때 띄워 둡니다.

## 사진·자료 파일 이름
사이트에 넣을 파일 이름은 **영문 소문자·숫자·밑줄만** 씁니다. 예: `sky01_unsplash_annaschmidt.jpg` — 내 사진의 주제·번호·사이트·작가로 바꿔 씁니다.
한글·공백·괄호가 들어가면 사이트에서 사진이 안 뜹니다. 고른 뒤 **site/assets/**에 넣기 전에 이름부터 바꿔 두면 STEP 04에서 헤매지 않습니다. 출처는 STEP 04에서 Claude가 **site/assets/CREDITS.tsv**에 한 줄씩 적습니다.

## 낭독형(W05-C)을 고른 경우 — 인물 띠 일러스트는 선택입니다
낭독형 페이지 아래쪽에는 인물 그림이 한 줄로 서는 띠가 있습니다. 내 주제에 맞는 인물·오브젝트 그림을 **직접 그리거나 생성 도구로 만들어 넣는 것은 선택**이고, 없으면 띠를 비워 둡니다. 넣는 방법(투명 PNG·파일 이름·크기)과 비워 두는 방법은 그 시스템 **DESIGN.md** §8에 있습니다. 남의 일러스트(웹툰 캡처·핀터레스트 등)는 쓰지 않습니다.

## 주의
- 레퍼런스의 로고·사진·문구는 가져오지 않습니다. 규칙만 배웁니다.
- 내 사이트(**weeks/**`NN`**/site/**)는 무엇이든 바꿀 수 있습니다. 지우고 싶은 것, 넣고 싶은 것을 Claude에게 말하면 됩니다. **시스템** 폴더는 원본이라 그대로 두면, 언제든 처음 모습으로 되돌릴 수 있습니다.
- 유료 서체는 무료 대체 서체로 바꿉니다. Claude가 후보를 줍니다.
- 5주부터 시스템의 서체는 인터넷에서 받아 옵니다. 교실 와이파이가 느리면 서체를 바꾼 차이가 늦게 보일 수 있습니다.
- 비밀번호·토큰은 절대 입력창에 넣지 않습니다. GitHub·Netlify 로그인은 브라우저에 뜬 그 서비스 화면에서만 합니다.
- Claude가 "확인했다"고 하면 어떤 화면·파일로 확인했는지 되묻습니다.
- 나의 기준 한 줄은 내 문장입니다. Claude가 대신 정하지 않습니다.
- 같은 문제로 5분이 지나면 혼자 붙들지 말고 손을 듭니다.
