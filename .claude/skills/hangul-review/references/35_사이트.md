# 35 · 사이트 채널 — 사이트에서만 생기는 문장 문제 (W1~W7)

> 포트폴리오 사이트·퍼스널 브랜드 사이트·서비스 소개 페이지 공통. 디자인·SEO 점검은 범위 밖이다 — 여기서는 **화면에 찍히는 한글 문장**만 본다.

## 1. 자리별 규칙

| 자리 | 길이·형태 | 호흡 규칙(R1~R4) | 특히 볼 것 |
|---|---|---|---|
| 히어로 헤드라인 | 한두 줄 | 적용 안 함 | 비유면 서브카피가 하는 일을 문자 그대로 말하는가(W3) |
| 히어로 서브카피 | 한두 문장 | 적용 | "무엇을 하는 누구인가"에 답하는가 |
| 소개·About 본문 | 문단 | **적용** | 주어 일관(S3), 스타카토(R2), 상투어(A1) |
| 서비스·작업 카드 | 제목 + 1~3문장 | 제목은 안 함, 설명은 적용 | 기계적 병렬(A5) |
| 케이스 스터디 본문 | 문단 | **적용** | 논항 복원(S1), 반복(A6), 사실(00 §2) |
| 버튼·CTA | 동사로 끝나는 짧은 구 | 적용 안 함 | 행동 하나를 요청하는가(W5) |
| 내비·라벨·태그·숫자 라벨 | 단어 | 적용 안 함 | 맞춤법·표기 통일만 |
| 이미지 alt | 한 문장 | 적용 안 함 | 보이는 것을 사실대로 쓰는가(W6) |
| title·meta description | 한 문장 | 적용 | 상투어·과장(A1·A2) |

## 2. 사이트 고유 실패

| ID | 이름 | 판정 | 심각도 |
|---|---|---|---|
| **W1** | 결론이 뒤에 있음 | 섹션 첫 문장이 배경·인사·자기소개로 시작하고 핵심은 세 번째 문장에 나옴 | 🟡 |
| **W2** | 치환 테스트 실패 | **이름을 지우고 다른 사람·다른 브랜드 이름을 넣어도 그대로 성립하는 문장**. `사용자 중심의 디자인으로 브랜드의 가치를 전달합니다`. 구체적 닻(실제 작업·장면·수치·도구·결정) 하나가 있어야 그 사람의 문장이 된다 | 🟡 · 히어로·소개 첫 문장이면 🔴 |
| **W3** | 첫 화면에서 하는 일을 모름 | 헤드라인과 서브카피가 둘 다 비유·추상어라 무슨 일을 하는 사람인지 문자 그대로 나오지 않음 | 🔴 |
| **W4** | 영한 반복 | 영문 헤드라인과 한글 서브가 같은 말을 번역만 해서 반복(`Design for People / 사람을 위한 디자인`). 영문은 정체성, 한글은 구체 정보로 역할을 나눠야 한다 | 🟡 |
| **W5** | CTA 모호 | `더 알아보기`·`Click`·`Go` 한 페이지에 여러 개 / 무엇이 일어나는지 모름 / 존재하지 않는 링크 | 🟡 |
| **W6** | alt 문제 | `이미지`·`사진1`·파일명 그대로 / 이미지에 없는 해석을 씀 | 🟢 |
| **W7** | 작업 흔적 노출 | `Lorem ipsum`·`[작성중]`·`TODO`·`여기에 텍스트`·`(수정 필요)`·영문 템플릿 기본 문구가 화면에 남음 | 🔴 |

## 3. 한 사이트 안의 통일

- 1인칭(`저`/`나`/브랜드명) 하나로 정했는가
- 존댓말 수준(`~합니다`/`~해요`) 섹션별로 정했는가
- 같은 대상을 같은 이름으로 부르는가(`프로젝트`/`작업`/`케이스`가 같은 걸 가리키면 하나로)
- 영문 병기는 첫 등장에만 했는가

통일 문제는 개별 문장으로는 안 보인다. **사이트 전체를 한 번에 읽고** 판정한다.
