# 40 · 판정과 출력 (검수 모드 전용)

## 1. 검수 절차

1. **대상을 전부 읽는다.** 사이트면 모든 페이지·모든 섹션. 일부만 받았으면 받은 범위를 첫 줄에 밝힌다.
2. **기계 검사 결과를 받는다.** `kcheck.py` 출력이 없으면 직접 돌린다. 찍힌 자리는 후보이지 판정이 아니다 — 하나씩 열어 사람 기준으로 확정하거나 기각한다.
3. **전수 패스 5회** — 한 번에 다 보려 하지 않는다. 패스마다 하나만 본다.
   1. 사실(00 §2)과 작업 흔적(W7)
   2. 비유 전수 추출(20) — 문서 전체의 비유를 한 목록에 모은 뒤 겹침·갈아타기·같은 말 다른 뜻을 본다
   3. 고립 읽기(30 §1) — 문장을 하나씩 떼어 "누가·무엇을"
   4. 소리 내어 읽기(10) — 끊어 내림과 억지 연결, 둘 다
   5. 사이트 전체 통일(35 §3)과 AI 티·맞춤법(30 §2·3)
4. **기각한 기계 후보도 남긴다.** "R3 후보였으나 강조용 마무리라 유지" 한 줄. 쓴 사람이 같은 자리를 다시 의심하지 않게 한다.
5. **이대로 두어도 좋은 것을 3개 이상 찾는다.** 지켜야 할 문장을 알려 주지 않으면 윤문 단계에서 그 문장까지 깎인다.

## 2. 심각도

| 등급 | 의미 | 해당 |
|---|---|---|
| 🔴 | 이대로 나가면 안 됨 | 사실 창작 · R1 · R2 · R5 · M2 · M3 · M4 · M8 · S1 · S4 · A1 · O1 · O2 · W3 · W7 |
| 🟡 | 읽는 사람이 한 번 멈춤 | R3 · R4 · R6~R8 · M1 · M5~M7 · S2 · S3 · A2~A7 · O3 · O4 · W1 · W2 · W4 · W5 |
| 🟢 | 선택 개선 | A8 · W6 · 쉼표 과다 · 취향 차원의 대안 |

🟡이라도 히어로·소개 첫 문단처럼 **첫 화면에 걸리면 한 단계 올린다.**

## 3. 판정

| 판정 | 조건 |
|---|---|
| `발행 가능` | 🔴 0건, 🟡 2건 이하 |
| `수정 후 가능` | 🔴가 있지만 문장 수정으로 해결된다 / 🟡 3건 이상 |
| `보류` | 사실 창작이 있음 / 원문 근거 없이는 고칠 수 없음 / 사이트 첫 화면에서 하는 일을 알 수 없음(W3)인데 쓴 사람 확인이 필요함 |

**🟢만 남았으면 추가 수정 라운드를 요구하지 않는다.** 선택 지적으로 루프를 돌리면 글이 닳는다.

## 4. 금지

1. **문장을 다시 쓰지 않는다.** 수정 방향은 종류까지만(`실제 행위로`·`인과면 한 문장으로`·`삭제`). 대체 문장을 쓰면 검수자가 생성자가 되어 누가 왜 바꿨는지 추적이 안 된다.
2. 구조 대개편을 제안하지 않는다. 기존 구조에 붙일 수 있는 지적만.
3. 원문에 없는 사실 추가를 제안하지 않는다.
4. 계측값을 목표치로 지시하지 않는다(`단문을 0개로` ❌).
5. 칭찬을 위한 칭찬, 쓴 사람에 대한 평가(`꼼꼼하지 못하네요`)를 하지 않는다. 판정은 문장에만 붙인다.
6. 추측 판정을 하지 않는다. 원문·자료를 확인 못 한 사실 문제는 `[확인 불가]`.

## 5. 출력 형식 (고정)

```markdown
판정: 발행 가능 / 수정 후 가능 / 보류
대상: <파일·페이지> (받은 범위: 전체 / 일부 — ○○만)
요약: 🔴 N · 🟡 N · 🟢 N — 가장 큰 문제 한 줄

| # | 심각도 | ID | 위치 | 원문 (그대로 인용) | 문제 | 수정 방향 |
|---|---|---|---|---|---|---|
| 1 | 🔴 | R2 | about.html · 소개 2문단 | "…" | 25자 이하 3연속 | 인과면 한 문장으로, 아니면 하나 삭제 |

## 비유 전수 목록
| 비유 | 위치 | 가리키는 대상 | 판정 (유지 / M#) |

## 기계 후보 중 기각
- R3 · index.html 12행 "…" — 문단 끝 강조라 유지

## 이대로 두어도 좋은 것 (3개 이상)
- "…" — 이유 한 줄

## 확인 불가
- 없음 / 항목
```

**위치**는 파일명 + 섹션(또는 행 번호)까지. 위치 없는 지적은 내지 않는다.
**원문**은 한 글자도 고치지 않고 인용한다 — 윤문가가 그 문자열로 찾아간다.
