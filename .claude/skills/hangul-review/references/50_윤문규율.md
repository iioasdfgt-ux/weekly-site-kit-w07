# 50 · 윤문 규율 — 고치는 손과, 고친 결과를 보는 눈

## 1. 윤문가 철칙 (위반하면 그 수정은 즉시 롤백)

1. **의미 불변.** 사실·수치·날짜·고유명사·인용·작품명·클라이언트명·링크 문구는 원문과 **한 글자도** 다르면 안 된다.
2. **근거 기반.** 검수표에서 **쓴 사람이 승인한 지적**만 고친다. 검수표 없이 윤문을 요청받으면 먼저 `hangul-reviewer`를 돌리라고 안내한다. 쓴 사람이 "검수 없이 바로"를 명시했을 때만 10·20·30·35의 🔴 항목에 매핑되는 곳을 직접 찾아 고치고, 그 사실을 출력에 적는다.
3. **말투 보존.** 원문이 `~해요`면 결과도 `~해요`. 격식을 올리거나 내리지 않는다. 구어 종결·질문형·1인칭을 줄이지 않는다.
4. **금지 조작 4종** — 원문에 없던 것을 만들어 내는 실수라 변경률 가드로는 안 잡힌다. 하나라도 하면 그 수정은 무조건 롤백한다.
   - **스타카토 생성**: 멀쩡한 복문을 짧은 문장 여러 개로 자름
   - **억지 연결 생성**: 관계없는 두 문장을 연결어미로 붙임
   - **비유 주입**: 원문에 없던 비유·의인화·수식을 얹음
   - **사실 추가**: 원문에 없던 수치·사례·평가를 넣음
5. **품질 보존 가드**(`00` §1 G1~G7) 전부 적용.

## 2. 유지율 — 재작성 경계선

```bash
python3 .claude/skills/hangul-review/scripts/kcheck.py --compare <원본> <윤문본>
```

- **문장 유지율 70% 미만이면 재작성이다.** 계속 쥐고 있지 말고 멈춘 뒤, 무엇을 살리고 무엇을 덜어낼지 적어서 쓴 사람에게 돌려준다.
- 반복(A6)을 삭제해서 분량이 준 경우는 예외로 본다 — 줄어든 것이 정보가 아니라 중복이면 성공이다. 출력에 그 사실을 적는다.
- **부분 수정 요청**("이 문단만")이면 그 범위 밖 변경은 0이어야 한다.

## 3. 파일을 고칠 때 — 원본 백업이 먼저

1. 고치기 전에 원본을 `_review/원본_YYYYMMDD-HHMM/<같은 상대 경로>`로 복사한다. **원본을 덮어쓰는 것으로 시작하지 않는다.** 외장 디스크·클라우드 동기화 폴더는 휴지통 복구가 안 되는 경우가 있다.
2. HTML은 **태그·클래스·속성·스크립트를 건드리지 않는다.** 텍스트 노드와 `alt`·`title`·`meta description`·`aria-label`의 값만 고친다.
3. 고친 뒤 `kcheck.py --compare`로 대조하고 결과를 출력에 붙인다.

## 4. 윤문 반영 점검 (검수자가 새 빈 컨텍스트에서)

윤문 도구가 만드는 실패는 쓴 사람이 만드는 실패와 종류가 다르다. 원문과 윤문본을 **나란히** 놓고 아래 9개를 본다.

| ID | 실패 | 보이는 모양 | 처리 |
|---|---|---|---|
| **P1** | 스타카토 생성 | 원문 복문이 짧은 문장 나열로 토막남 | 🔴 그 구간 원문 유지 |
| **P2** | 과개행 생성 | 개행이 늘어 한 문단이 흩어짐 | 🔴 그 구간 원문 유지 |
| **P3** | 비유 생성 | 원문에 없던 비유·수식이 생김 | 🔴 삭제 |
| **P4** | 목소리 소실 | 구어 종결·질문형·1인칭이 줄어 문어체로 눌림 | 🟡 위치 표시 |
| **P5** | 전문어 증발 | 업계 용어가 쉬운 말로 치환돼 사라짐 | 🟡 위치 표시 |
| **P6** | 사실 변경 | 수치·고유명사·인용·링크 문구가 한 글자라도 바뀜 | 🔴 롤백 |
| **P7** | 억지 연결 생성 | 단문을 없애려고 관계없는 문장을 이음 | 🔴 그 구간 원문 유지 |
| **P8** | 취향 재작성 | 검수표에 없던 문장이 바뀜 / 유지율 70% 미만 | 🟡 되돌림 |
| **P9** | 개성 절단 | 감각 묘사·뼈대 비유·말버릇이 사라져 무난해짐(G4·G7) | 🟡 위치 표시 |

**판정 한 줄: 원문과 윤문본을 소리 내어 읽고 더 자연스럽게 읽히는 쪽을 남긴다. 의심되면 원문이 이긴다.**

## 5. 윤문가 출력 형식 (고정)

```markdown
윤문 결과: 반영 N건 / 보류 N건 / 롤백 N건
원본 백업: _review/원본_YYYYMMDD-HHMM/  (텍스트 입력이면 "해당 없음")

## 윤문본
(텍스트 입력이면 전문. 파일 작업이면 생략하고 파일 경로만)

## 반영 내역
| # | 검수 ID | 위치 | 원문 | 수정 | 근거 한 줄 |

## 반영하지 않은 지적
| # | 검수 ID | 이유 (나아지지 않음 / 관계 없는 문장이라 잇지 않음 / 사실 확인 필요 …) |

## 대조 (kcheck --compare)
- 문장 유지율 N% · 새로 생긴 단문 연속 N · 새 비유 후보 N · 바뀐 숫자 N · 구어/질문 종결 전→후
- 의미 불변: 수치·고유명사·인용·링크 원문과 100% 일치 (예/아니오)

## 쓴 사람만 정할 수 있는 것
- [확인 필요] …
```
