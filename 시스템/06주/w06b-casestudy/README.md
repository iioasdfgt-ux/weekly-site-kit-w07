# W06-B 사례형

**대표 사진 위로 정보 카드가 올라와 멈추고, 바탕색 안개가 그 카드를 덮으며 이미지 판이 한 줄씩 떠오릅니다.** 작업 한 건을 깊게 보여 주는 페이지입니다. 첫 화면은 사진과 제목뿐이고, 읽을 글은 직각 카드 한 장에 모여 있으며, 나머지는 이미지 배열이 말합니다. 위계는 크기보다 **겹치는 순서**(사진 → 카드 → 이미지 판)로 만듭니다.

- 레퍼런스: this.design — Skylab 사례 페이지 · https://this.design/work/skylab (디자인 스튜디오의 프로젝트 소개)
- 이런 사람에게 맞습니다: 보여 줄 작업이 한 건이고 과정 사진이 여러 장 있을 때, 설명은 짧게 한 번에 읽히고 나머지는 사진으로 보여 주고 싶을 때, 대표 사진 한 장이 확실할 때.

## 먼저 볼 것
- 샘플 글이 채워진 예시: `golden_sample.html` (가상의 학생 윤서하 · 7주 기준 메뉴 다섯 칸과 4장 물건까지 채운 모습)
- `golden.html`을 더블클릭하면 예시 페이지가 열립니다. 모든 글은 `[프로젝트 제목]`처럼 칸 이름이 적힌 자리표시입니다. 천천히 스크롤해 보세요 — 카드가 사진 위로 올라와 멈추고, 흰 안개가 덮은 뒤 사진들이 떠오릅니다.
- `examples/`의 세 페이지는 같은 시스템을 극한 조건에 넣은 것입니다. `b`는 긴 제목·긴 글, `d`는 사진이 대표 사진 1장뿐, `f`는 사진이 한 장도 없는 경우입니다.
- 빠른 커스텀 항목은 `my-style.css`의 여섯 줄입니다(이 시스템만의 고유 항목은 없습니다). 이 밖의 것도 말하면 바꿔 줍니다.
- 움직임은 `shots/golden_1280.gif`와 `shots/ref_1280.gif`(원 사이트)를 나란히 보면 비교됩니다.

## 수업에서 쓸 때
이 폴더는 원본이라 그대로 둡니다(언제든 처음 모습으로 되돌릴 수 있게). STEP 02에서 이 시스템을 고르고, STEP 04에서 Claude가 `golden.html`을 내 주차 폴더로 복사해 내 글과 사진으로 칸을 바꿉니다. 그다음부터는 내 사이트에서 무엇이든 바꿀 수 있습니다 — `my-style.css`의 커스텀 항목은 물론, 카드·이미지 줄·관련 작업 타일을 지우거나 더하거나 옮겨 달라고 말하면 Claude가 그대로 해 줍니다. 순서는 그 주의 주제카드를 따릅니다.
