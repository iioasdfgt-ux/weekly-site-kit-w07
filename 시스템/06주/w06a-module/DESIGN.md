## 1. 정체
정보가 **모서리 표식(6px 네모 넷)이 달린 1px 상자**에 한 칸씩 담긴다. 상자는 선 하나를 공유하며 위아래·옆으로 붙어 도면처럼 쌓인다. 목록에서 **누른 모듈 하나만 열리고**(처음엔 첫 모듈), 열린 모듈은 제목이 18→22px로 커지고 설명과 100px 여백이 펼쳐진다. **위계 = 지금 열린 모듈.** 섹션은 전부 같은 격자(왼쪽 1/3 섹션 이름 · 오른쪽 2/3 한 문장 + 모듈)를 쓰고, 섹션 사이는 200px 비운다.

## 3. 좋아 보이는 이유 3 (화면 위치)
1. **소개 섹션 오른쪽 1/3** — 모서리 표식 상자가 선을 공유하며 쌓인 목록. 열린 한 칸만 크고 나머지는 한 줄이라, 항목 수가 많아도 한눈에 "다섯 개 중 지금 이것"이 읽힌다.
2. **모든 섹션의 왼쪽 1/3 · 오른쪽 2/3** — 작은 섹션 이름과 큰 문장이 매번 같은 자리에 온다. 섹션마다 모양이 달라도 스크롤 내내 같은 격자 위를 걷는다.
3. **시리즈 무대** — 화면 높이 사진 위에 흐린 유리 상자. 목록 한 줄을 누르면 화면 전체 배경이 바뀌어, 작은 선택이 큰 장면을 움직인다.

## 4. 레이아웃 골격
화면 가장자리 40px(모바일 20px). 두 가지 격자만 쓴다: 소개 `2fr | 1fr`, 나머지 `1fr | 2fr`.
```
상단 바   [이름 칸 · 화면 절반            ][메뉴1][메뉴2][메뉴3][메뉴4]   ← 고정, 위 20px
① 첫 화면  100svh 사진(밝기 .8 + 검정 40%) · 가운데 높이 왼쪽 [대표 제목]
② 소개     [소개 문장 ──────── 2/3 ][모듈 목록 1/3 (sticky 100px)]
           [400px 비움]
           [3:2 큰 사진 ─────────── ]
   200px
③ 대상     [섹션 이름 1/3][섹션 문장 2/3]
                          [모듈 A][모듈 B]      ← 나란히, 선 공유
④ 과정     [과정 이름][섹션 문장]
                     [01 단계 제목 · 설명 3:2 칸 | 사진(열렸을 때만)]
                     [02 …] … [06 …]           ← 닫힌 단계는 한 줄
⑤ 시리즈   [이름][섹션 문장]
           [100svh 무대: 배경 사진 · 왼쪽 1/3 흐린 유리 모듈 셋]
⑥ 세부     [이름][섹션 문장 · 화살표 링크 · 3:2 판(+ 점) · 아래쪽 장면 탭 셋]
⑦ 연락     옅은 포인트 면 [연락 제목·안내][칸 격자 2열: 전폭 ▾ / ▾ ▾ / 값 값 / 전폭 연락 문장 + 버튼]
끝줄       [이름 34px][소식 링크] … 150px … [작은 글][주소][연락처][채널][메뉴][사진 출처]
떠 있는 버튼 왼쪽 아래 40px, 폭 297px
```
모바일(≤768): 모든 격자가 한 줄로. 상단 바 = 이름 칸 + "메뉴" 칸(누르면 아래로 메뉴 칸이 .5초에 펼쳐짐). 과정 사진은 열린 단계 글 아래. 세부 탭은 판 아래로 내려오고 카드는 화면 가운데(×로 닫음). 섹션 사이 200px 대신 섹션 안 40px.

## 6. 커스텀 항목 (my-style.css)

**명암: 자유** — 짙은 바탕이면 선·글자가 밝게 뒤집히고 사진 없는 면은 바탕보다 10% 밝게 선다. 짙은 바탕 요청은 멈추지 않고 적용한다. 아래 표는 빠른 커스텀 줄이고, 표에 없는 요청도 복사본을 고쳐 들어준다.

| # | 변수 | 값 | 이 시스템에서 |
|---|---|---|---|
| 1 | `--my-bg` | 색 | 종이(모든 섹션 바탕). 밝으면 먹 = 원본 짙은 갈색, 짙으면 먹 = 바탕+흰 90%. 대비 4.5:1 미만이면 글자만 보정 |
| 2 | `--my-point` | 색 / `none` | 떠 있는 버튼·연락 버튼·+ 점 면, 연락 면(포인트 60% + 바탕), 세부 카드(85%). 포인트가 밝으면 사진 위 글자·선도 이 색(원본 옅은 청회색 자리). none → 바탕과 먹 15% 사이 회색 |
| 3 | `--my-type` | `sans`(기본) · `serif` · `mono` · `hand` | sans = **제목·라벨 Pretendard 600 + 모듈 본문 Noto Serif KR**(원본 짝: 고딕 제목 + 명조 본문) · serif = Noto Serif KR 전체 · mono = Nanum Gothic Coding 전체 · hand = Jua 제목 + Gowun Dodum 본문 (넷 다 제공) |
| 4 | `--my-motion` | `0` · `1`(기본) · `2` | 0 = 모듈·사진·탭이 전환 없이 바로 바뀜(상단 바 숨김 규칙은 유지) · 2 = 첫 화면 사진이 1.06배에서 2.4초에 가라앉고, 섹션이 들어올 때 24px 아래에서 떠오름 |
| 5 | `--my-density` | `0` · `1` · `2` | 0 = 섹션 사이 280px · 가장자리 56px / 2 = 섹션 사이 120px · 본문 18→20.5px · 섹션 문장 27→31px |
| 6 | `--my-image` | `native`(기본) · `original` · `mono` · `tint` | native = 첫 화면 사진 밝기 .8 + 검정 40%(원본 처리), 세부 판 아래쪽 옅은 그늘 / original = 첫 화면 검정 25%만 / mono = 전부 흑백 / tint = 흑백 + 포인트 곱하기 |
| 7 | `--mo-mark` (고유) | `6`(기본) · `10` · `0` | 모서리 표식 크기(px). 0 = 선만 |

**고유 항목 번역(선택 기록 칸)**: `--mo-mark` → **밀도** 칸에 "모서리 표식 6/10/0"으로 적는다.

**말투 보충(COMMON §4 v2.1)**: "은은하게·부드럽게" = `--my-motion: 1`. "글자는 ○○색" = 이 시스템은 글자색을 바탕에 맞춰 자동으로 정하므로 `--my-point`에 넣고 글자색 요청 보고 줄(밝은 포인트는 사진 위 글자에만 쓰인다). "도면 같은 네모 빼 줘" = `--mo-mark: 0`.

## 7. 기본값 5 — AI가 **스스로** 바꾸지 않는 것 (학생이 요청하면 바꾼다)
학생이 아래 항목을 바꿔 달라고 하면 그대로 바꾼다. 거절하거나 다른 시스템을 권하지 않는다. 학생 요청 없이 AI가 조립 중에 임의로 바꾸지만 않으면 된다.
1. 한 번에 모듈 하나만 열린다(sig.js가 첫 모듈을 연다). "다 펼쳐 줘"·"카드로 바꿔 줘"면 복사본 sig.js·style.css를 고쳐 그렇게 한다.
2. 면·선 색은 `--my-bg`·`--my-point`에서 나온다. 학생이 특정 자리에 다른 색을 원하면 `my-style.css`에 변수를 한 줄 더 만들어 그 자리에 쓴다.
3. 격자는 소개 2:1, 나머지 1:2. "사진을 크게"·"격자를 반반으로" 같은 요청은 복사본 style.css를 고쳐 들어준다.
4. 선은 1px·직각·그림자 없음. 굵게·둥글게·그림자 요청도 들어준다.
5. 스크롤을 가로채지 않는다(학생이 스냅·부드러운 스크롤을 원하면 넣되, 모바일에서 스크롤이 막히지 않는지 한 번 확인한다).

## 8. 조립 규칙 (COMMON_RULES 외 고유분)
- **고정 라벨**(시스템 문구, 그대로 둔다): "메뉴 / 닫기", 단계 번호 01~, "사진:" 출처 머리, →·▾·+·× 기호, `<title>` 끝줄 규칙.
- **표시 변환**: 대소문자·세로쓰기 변환 없음. 단계 번호만 sig.js가 제목 앞에 붙인다(원문은 그대로).
- **사진은 칸 안에 둔다**: 단계 사진은 그 단계 모듈 안, 시리즈 배경은 그 시리즈 모듈 안(`figure.mo-bg`), 세부 사진은 그 장면 안. sig.js가 제자리로 옮긴다. 사진을 따로 모아 두지 않는다.
- 세부 점 위치는 `style="--x:NN%;--y:NN%"`(사진 판 기준 백분율)만 쓴다. 학생이 위치를 말하지 않으면 golden 위치를 그대로 두고 `점 위치 기본값` 보고. 주제카드가 점 위치를 정해 두었으면(6주: 25·35 / 70·30 / 50·70) 그 값을 쓴다.
- 연락 칸은 입력 칸이 아니다(폼·입력·제출 없음). ▾ 칸의 값·다른 값은 학생 문구다.
- 링크 주소를 학생이 주지 않았으면 `href="#"` 그대로 + `링크 주소 없음: 라벨` 보고. 메뉴 `href`는 섹션 id(`#s1`~`#s6`) — 섹션을 지우면 그 메뉴도 지운다.
- `og:image` = 첫 화면 사진(없으면 첫 사진, 0장이면 태그째 삭제 — site-qa의 OG WARN 1건은 의도된 결과).
- 대비 보정·사진 0장은 sig.js가 `<html data-mo-report>`에 남긴다 → AI는 그 문구를 보고 줄로 옮긴다.
- 요청이 "목록을 다 펼쳐 줘"면 복사본 sig.js의 '하나만 열림'을 풀어 전부 펼친다. 적용 뒤 "이제 모듈이 모두 펼쳐진 채로 보입니다" 한 줄만 알린다.
- 예시 표기 `.note`는 학생 페이지에서 태그째 지운다.
