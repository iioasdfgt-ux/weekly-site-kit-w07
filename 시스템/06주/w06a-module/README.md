# W06-A 모듈형

**정보가 모서리 표식이 달린 1px 상자(모듈)에 한 칸씩 담기고, 누른 모듈 하나만 열립니다. 위계는 지금 열려 있는 모듈이 만듭니다.**
모든 섹션이 같은 격자를 씁니다. 왼쪽 1/3에는 섹션 이름, 오른쪽 2/3에는 한 문장과 그 아래 모듈 목록이 옵니다. 모듈을 누르면 제목이 커지고 설명이 펼쳐지며, 과정 단계는 옆에 사진이 켜지고 시리즈는 화면 전체 배경이 그 모듈의 사진으로 바뀝니다.

- 레퍼런스: TEKT — https://tekt.com.au/ (호주 모듈러 주택 회사. 홈에서 오른쪽 목록 → 과정 여섯 단계 → 사진 위 시리즈 → 사진 위 + 점 순서로 직접 눌러 보세요. `/process/`·`/design/`·`/faqs/` 하위 페이지도 같은 상자 문법입니다)
- 이런 사람에게 맞습니다: 보여 줄 것이 **여러 항목의 목록**(가치 다섯, 단계 여섯, 장소 셋)이고, 한 번에 하나씩 열어 읽게 하고 싶을 때
- 사진이 없어도 됩니다. 사진 칸을 지우면 첫 화면·시리즈 무대는 짙은 면, 세부 판은 옅은 포인트 면이 되고 모듈은 그대로 열리고 닫힙니다.

## 먼저 볼 것
- 샘플 글이 채워진 예시: `golden_sample.html` (가상의 학생 윤서하 · 7주 기준 메뉴 다섯 칸과 4장 물건까지 채운 모습)
- `golden.html`을 더블클릭하면 브라우저에서 예시 사이트가 열립니다. 글은 모두 `[칸 이름]` 자리표시입니다 — 그 자리에 내 글이 들어갑니다.
- 오른쪽 모듈 제목을 눌러 보세요. 열린 하나만 커지고 나머지는 한 줄로 접힙니다. 시리즈 모듈을 누르면 배경 사진이 바뀌고, 세부 사진 위 **+** 를 누르면 설명 카드가 뜹니다.
- `examples/`의 세 페이지는 같은 시스템에 구조를 일부러 괴롭힌 것입니다. `b`는 긴 제목·긴 본문, `d`는 사진 1장뿐, `f`는 사진 0장(검정 바탕)입니다.
- 움직임은 `shots/golden_1280.gif`와 `shots/ref_1280.gif`(원 사이트)를 나란히 보면 비교됩니다.
- 이 시스템의 빠른 커스텀 항목은 `my-style.css`의 일곱 줄입니다(공통 여섯 + 모서리 표식 크기). 이 밖의 것도 말하면 바꿔 줍니다.

## 수업에서 쓸 때
이 폴더는 원본이라 그대로 둡니다(언제든 처음 모습으로 되돌릴 수 있게). 이 시스템을 고르면 Claude가 STEP 04에서 `golden.html`을 내 주차 폴더로 복사해 `[칸 이름]` 자리를 내 글과 사진으로 바꿉니다. 그다음부터는 내 사이트에서 무엇이든 바꿀 수 있습니다 — `my-style.css`의 커스텀 항목은 물론, 모듈·섹션·사진 칸을 지우거나 더하거나 옮겨 달라고 말하면 Claude가 그대로 해 줍니다. 순서는 그 주의 주제카드를 따릅니다.
