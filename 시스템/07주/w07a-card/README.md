# W07-A 카드형

**아카이브의 모든 장이 12단 격자 위 같은 모양의 카드(사진 → 이름 → 두세 줄 → More)로 서고, 카드를 누르면 사진이 먼저 나오는 큰 상세가 열립니다. 위 바에는 이름과 장 메뉴 다섯 칸, 아래 바에는 연락처가 붙어 판을 받칩니다.**

들어가는 말부터 1장 시선 · 2장 사람 · 3장 공간 · 4장 물건 · 기준이 쌓이는 자리까지, 6주에 W06-A·B로 만든 아카이브와 **같은 장 · 같은 칸**입니다. 6주에 채운 글과 사진을 그대로 옮겨 부으면 됩니다. 메뉴는 화면 **위** 바의 다섯 칸이고, 한글(시선 · 사람 · 공간 · 물건 · 기준)로 할지 영문(Gaze · People · Spaces · Objects · Criteria, 기본)으로 할지는 처음에 Claude가 묻습니다. 화면 **아래** 바에는 Email · Instagram · ©연도가 있습니다 — 공개 주소에 올릴 때는 넣고 싶은 연락처만 남깁니다.

- 레퍼런스: Jack McEntee — https://jackentee.com (그래픽 디자이너 개인 사이트. 작업 이미지 아래 캡션과 선, 큰 이름 목록, 작업 이미지를 누른 뒤의 상세, 화면 가장자리에 붙은 바를 보세요)
- 이런 사람에게 맞습니다: 사진의 원래 모양(세로·가로)을 상세에서 자르지 않고 보여 주고 싶을 때. 여러 장의 항목을 **같은 모양의 카드로 나란히** 정리하고 싶을 때.
- 사진이 없어도 됩니다. 사진이 없는 카드는 이름과 글만 섭니다.

## 먼저 볼 것
- `golden.html`을 더블클릭하세요. 가상의 학생 윤서하의 글과 사진으로 다섯 장을 다 채워 둔 예시입니다. 1·2·4장은 카드가 모두 열려 나란히 서고(카드 섬네일은 4:5), 3장 공간은 왼쪽 공간 목록 · 오른쪽에 흩어 둔 정사각 사진 칸입니다. 칸이나 목록에 마우스를 올려 보고, 카드 이름이나 **More**를 눌러 상세를 여세요. 상세에서는 화면 좌·우 가장자리(또는 ←/→ 키 · 휴대폰은 옆으로 밀기)로 넘기고, Esc · 위 바의 제목 · 장 메뉴 · 브라우저 뒤로가기로 닫힙니다.
- 휴대폰 폭에서는 위 바가 두 줄(제목 / 메뉴 다섯 칸)이 되고 카드는 세로로 쌓입니다. 아래 바는 그대로입니다.
- `examples/` — `b` 긴 이름·긴 제목·물건 2개(밀도 2), `d` 짧은 이름·사진 적음·거친 문장(명조·움직임 0), `f` 사진 0장·흑백 요청.
- 원 사이트와 나란히 본 화면: `shots/compare_1280.png`.
- 빠른 커스텀은 `my-style.css` 여덟 줄(공통 여섯 + 자동 넘김 + 메뉴 언어). 이 밖의 것도 말하면 바꿔 줍니다. 자세한 칸과 규칙은 `DESIGN.md`(v2.2)에 있습니다.

## 수업에서 쓸 때
이 폴더는 원본이라 그대로 둡니다. 이 시스템을 고르면 Claude가 `golden.html`을 내 주차 폴더로 복사하고, 6주 아카이브(W06-A·B)에 넣었던 글·사진을 같은 칸에 옮긴 뒤 4장 물건을 채웁니다. 그다음부터는 무엇이든 바꿔 달라고 말하면 됩니다.
