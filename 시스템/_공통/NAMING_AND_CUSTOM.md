## 2. 공통 커스텀 항목 (모든 주·모든 시스템 같은 변수 이름)

아래 **여섯 줄은 모든 시스템에 똑같은 이름으로** `my-style.css`에 있는 빠른 커스텀 줄이다. 이 밖의 요청(요소 삭제·추가·구조 변경)도 학생 사이트 복사본을 고쳐 들어준다(COMMON_RULES §0). 시스템 고유 항목은 최대 2줄까지 더할 수 있고, 각 고유 항목은 아래 공통 칸 중 어디에 해당하는지 한 줄 번역을 DESIGN.md에 적는다.

| # | 공통 항목 | 변수 | 값 | 8주 기록 칸 |
|---|---|---|---|---|
| 1 | 바탕 색 | `--my-bg` | 색 코드 | 색 |
| 2 | 포인트 색 | `--my-point` | 색 코드 (없음 = `none`) | 색 |
| 3 | 서체 짝 | `--my-type` | `serif` 명조 · `sans` 고딕 · `mono` 고정폭 · `hand` 손글씨·둥근 (시스템마다 넷 중 3개 이상 제공, 기본값 1개) | 서체 느낌 |
| 4 | 움직임 | `--my-motion` | `0` 조용함 · `1` 기본 · `2` 강함 | 움직임 |
| 5 | 밀도 | `--my-density` | `0` 비움 · `1` 기본 · `2` 꽉 | 밀도 |
| 6 | 이미지 처리 | `--my-image` | `original` 원본 · `mono` 흑백 · `tint` 색 덮기 · `native` 이 시스템 고유 처리(예: ASCII, 조각 크롭) | 이미지 |

- 서체 짝 값은 **느낌 이름**이다(시스템마다 실제 서체는 다르다). 그래서 8주 표에서 "매번 serif" 같은 반복이 읽힌다.
- 모든 값 조합에서 사이트가 깨지지 않아야 한다(시스템의 책임).
- 시스템 기본 모양과 다른 값도 그대로 적용한다(COMMON_RULES §0). 거절하지 않는다.

```
# W05 선택 기록
- 고른 시스템: W05-C 낭독형
- 고른 이유(학생 말 그대로): …
- 바탕 색: #FFFFFF / 포인트 색: none
- 서체 느낌: sans
- 움직임: 0
- 밀도: 0
- 이미지: native
- 고유 항목: 차오름 outline → 움직임
- 바꾼 요소(커스텀 — 여러 개면 줄을 나눈다): …
- 기준 한 줄: …
```
